###### Посилання на репозиторій(можливо так зручніше): <>

### Потребує наголошення:
- Типи нерухомості, скоріш за все, могли бути інамом, але т.я. вони вказані сутністю - сутністю вони и залишаються
- Сутність клієнта не має інформації про тип. По перше - можливо, один і той самий клієнт може бути як покупцем так і продавцем. По друге дані про тип клієнту можуть бути отримані з RealEstate та Showings - якщо користувач має зареєстровану нерухомість / був учасником оглядів; він відповідно є продавцем та/або покупцем.
- Продаж є прив'язаним до огляду, що допомагає уникати дублювання (інакше продаж мав би зберігати дані про агента та ін.).
- Сутність менеджменту дозволяє запис без вказаного агенту - припускається що нерухомість може бути проданою без агента. Тобто в випадку коли замість id агенту вказано null, ми вважаємо що нерухомість продається власником.
- Ціна нерухомості на продажу виділені окремо, т.я. припускається що під час огляду могла бути домовленість про зміну ціни.
- До сутності нерухомості додан аттрибут часу реєстрації щоб рахувати середній час на ринку до продажу.
- Статус нерухомості є обчислюємим
